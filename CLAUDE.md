# inkfetch

E-paper frame that pulls its picture: ESP32 firmware (`firmware/`) and a Python
reference server and converter (`tools/`). The README is the user-facing reference,
including the frame ↔ server contract.

## Layout

- `firmware/lib/inkfetch_core/`: hardware-independent C++ (PNG decoding, palette
  mapping, refresh policy, Retry-After, OTA manifest, settings validation). Must not
  include Arduino or ESP-IDF headers: it is tested on the host.
- `firmware/src/display/<profile>.cpp`: everything display-specific, behind
  `firmware/src/profile.h`. One PlatformIO env per profile (`seeed-ee02` for now).
- `firmware/src/app/`: Wi-Fi/HTTP, OTA, NVS settings, WiFiManager portal;
  `firmware/src/main.cpp`: the wake → fetch → refresh → sleep cycle.
- `tools/src/inkfetch/`: palettes, image rendering, server (file and proxy mode),
  OTA manifest, CLI.
- `fixtures/`: PNG + expected native indices shared by Python and native tests,
  generated by `tools/scripts/make_fixtures.py`.

## Commands

```sh
(cd firmware && pio test -e native)        # core tests, no hardware
(cd firmware && pio run -e seeed-ee02)     # firmware build
(cd tools && pytest)                       # tools tests
python tools/scripts/make_fixtures.py      # after changing palettes or fixtures
```

Run all three before committing a change that touches the firmware or the contract.

## Rules

- Everything in the repository is in English (code, comments, logs, docs).
- The server does all image work. The firmware only decodes an indexed PNG at the
  panel's size and maps palette entries to the nearest native ink; never add
  resizing or dithering to the firmware.
- Panel protection is not negotiable: at least `minRefreshS` (180 s on Spectra 6)
  between refreshes whatever the trigger, at least one refresh per `maxStaleS`
  (24 h), panel powered off before deep sleep, no tight wake loops. Any change to
  the cycle or the policy keeps these, with native tests in
  `firmware/test/test_core/`.
- `nearest_native` (Python) and `nearestNative` (C++) must stay identical: squared RGB
  distance, lowest index on ties.
- A change to the contract (query parameters, headers, PNG format, palettes) updates
  both sides, their tests and the README together.
- The board has not been tested on hardware yet: never claim something was verified
  on the device.

## Commit messages

One line: a short action in the imperative. **No body, no trailer, no watermark** (`Co-Authored-By`, `Claude-Session`,
`Generated with` are refused by the commit guard). One logical change per commit; the `commit`
skill gives the isolation rules and the order.
